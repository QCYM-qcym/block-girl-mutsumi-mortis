## 1. 已确认的方向与本轮范围

用户认可 V3 的圆形工具入口、轻薄半透明抽屉及整体操作感觉；下一版将放大的方块娘及其待机小动作作为**菜单背景**。菜单主要内容放在左侧，角色位于中右侧，保留脸部与轮廓的可读性。背景不再展示关卡几何，不提供实时可玩关卡，也不将角色展示伪装成实际游玩画面。

Surface / Inner 切换必须同时改变角色与整套 UI 配色，包括背景、抽屉、按钮、选中态、边线、焦点和次级文字；不能只更换角色而保留同一 UI 色调。两套色彩维持 V3 的低饱和、清楚文字层级和克制透明感，具体观感由 V4 预览审核。

新预览位于 `docs/beta-sprint/ui-motion-upgrade-04/design_preview/`。本轮只制作并验证这个隔离浏览器样例；不修改 Godot 产品场景、Runtime、Save、输入合同、角色 sampler、World Shift 生命周期或冻结美术。后续正式游玩继续使用现有真实场景，不把菜单展示场景接作游戏关卡。

## 3. 菜单、交互与配色

保留 V3 的统一圆形线图标工具、清晰中文提示、可见键盘焦点，以及按需展开的半透明抽屉。菜单和面板不挡住角色脸部；窄窗口优先调整构图、滚动内容和保留可达操作，不通过无限缩小文字解决空间不足。

原型中的世界切换只是菜单展示状态，切换角色与配色不能被解释为 Runtime 的 World Shift。旅程、设置、暂停等内容若被展示，继续明确其样例身份；不读取真实完成进度，不制造新解锁、统计、音乐播放或存档成功承诺。

输入和设置修改仅存在于当前页面内存。关闭或刷新原型不保存配置，不写 localStorage、SaveStore 或正式设置文件。正式设置的预览、应用、取消、失败恢复以及暂停恢复合同仍沿用 V3，留待批准后的产品接入与实测。

## 4. 原型技术与动态行为

浏览器预览局部随附 Three.js `0.186.1`（MIT）渲染器与 GLTFLoader 及其必需加载依赖，使用该 npm 版本提供的官方未压缩文件，保持原文件内容。源码、许可与来源记录只放在预览目录内，只为读取上述 GLB 并评审菜单构图。它们不是新增 Godot 游戏依赖，也不构成替换正式渲染或角色控制器的方案。

常规模式允许克制的整体待机动作与短面板过渡。系统或页面启用减少动态时停止角色及其他非必要循环运动，状态切换仍立即可辨。页面隐藏时暂停动画与渲染循环，返回时平稳恢复，避免累积隐藏时长造成跳变；面板快速切换、关闭仍即时响应。
