# 悬空 roof：两种最小视觉方案，只读研究

2026-10-13（Asia/Shanghai） · Owner 05 · `SPATIAL_PUZZLE_ACCEPTANCE_CONTINUATION_02`

基线 `295a4702aeb17d6fced11cfdaa221e0ffa90dd12`，工作分支 `docs/spatial-art-continuation-02`。本报告只提出视觉方案，没有制作图片、资产、场景或代码，没有启动 Godot / Blender / 浏览器，没有访问外部美术目录。正式美术仍为 `PENDING_USER_REVIEW`，方案验证为 `NOT_RUN`。提交和推送由本轮主代理统一完成。

## 结论与目标

推荐先评审 **A：连续粗纹实体表皮**，保留 **B：内收封闭边缘标记** 作为对照。两者都保留 roof 的完整不透明方块轮廓、体积、位置与投影遮挡关系；区别通过表面纹样实现，不添加可踏边、支架、透明孔或新的动作提示。

目标是让玩家更容易把 roof 认作不可站立的实体遮光体，同时避免误读成装饰、玻璃或失效平台。纯视觉只能提供身份线索，不能保证玩家首次便推导出完整世界转换规则。尤其不能把“非可走”与“遮光”合并成同一分类：本图可行走的 gate 和 source 同样具有 `occludes_light=true`。

## 方案 A：连续粗纹实体表皮（优先评审）

**具体改变。** 保留当前克制灰蓝色与不透明外轮廓，仅为 roof 增加低频、闭合且贯穿顶面与侧面的石质粗纹：每面只保留 2–3 条较宽、不等距的钝弧纹；纹线在相邻面延续，使它读成同一完整实体的表皮。采用明度差与粗糙度差，不依赖色相；细噪点和细沟槽不作为必要信息。纹样不得画成洞、层层台阶、栏杆、箭头或棋盘格，也不新增真实几何凹凸和轮廓变化。

**预期收益（待验证）。** 道路保持既有平面表达，roof 的顶面与侧面连续处理削弱“上面是一块独立踏板”的分区感；其厚实实体感和遮光可信度继续保留。世界内材质表达较克制，侵入性低，不占用 Face Lock 的面符号词典。

**可能误导。** 粗纹也可能像攀爬岩壁，或仅被视为可走平台的新材质；纹路过暗会与阴影混淆，过密会在小尺寸消失。因此粗纹必须宽而稀疏，避免梯状水平等距线，不宣称材质本身足以教会“不可走”。

**四视角/小尺寸。** 四个侧面使用等价的纹样覆盖密度，至少一条粗纹跨越每个上缘，Q0–Q3 均能同时看到顶面与侧面上的连续身份线索。以原生 960×720 图先验收：最长可见纹线不能退化为单像素噪点，临时比较目标为主体纹线至少约 3 px 宽，具体尺寸需实机截图确定。灰度查看后仍应能区别平滑道路与粗纹 roof。禁止为通过测试放大物体或改相机。

**制作范围与风险。** 如另行批准：1 个 roof 专用不透明材质、1 张可重复映射的低频表面纹样；复用现有网格，0 个新 Blender 模型，0 个 VFX，0 个 Runtime 判定。对同一对象做显式表现绑定，不写“看材质就禁止走”的逻辑。预算估计 0.5–1 人日材质与映射、另 0.5 人日四视角采集/调整；不含首次玩家招募。主要风险是区别有了但语义仍未建立，须靠观察决定是否有效。

## 方案 B：内收封闭边缘标记（对照）

**具体改变。** 保留平整实体材质，只在现有表面内画封闭边缘身份：顶面内缘一圈深浅双带，每边中段有一个粗短横向封口；四个侧面的上沿各延续同样短封口。它是贴在实心表面的图案，没有外挑檐口、可踏边、立体围栏或透明内芯。所有笔画压在现有轮廓内部，不借描边扩张物体或改变遮挡；保持全部不透明。

**预期收益（待验证）。** 明确且重复的封闭图案可在较小尺寸下提供比细材质更强的类别线索；顶面仍是实体，但不再与普通无标记路面相同。它是静态物体身份，没有开/关或锁存含义。

**可能误导。** 边框可能让玩家误判为 Pressure Plate、Face Lock 或尚待激活的平台，这是本方案的主要成本。必须避开浅色中央嵌面、金色目标面符号、READY/MATCHED 横闩和黄黑危险条；封口始终固定，不发光、不移动、不随 Runtime 可用性变色。若真人仍把它当机关，舍弃此方案，不追加第二套状态说明来补救。

**四视角/小尺寸。** 每边同等粗细和封口数量，避免某个视角只剩空白顶面；在 960×720 原生显示时连续封闭关系不能因抗锯齿断裂。初步校核目标为主带约 3–4 px 可见宽度，并在最暗侧仍看见至少一个封口。图案只能说明类别，不能依赖读字或颜色。必须与同尺度 Pressure Plate / Face Lock 同屏对照，记录“误认为机关”次数；已有本报告截图没有该对照，结果 `NOT_RUN`。

**制作范围与风险。** 如另行批准：1 张内缘封闭纹样、1 个 roof 专用材质；复用现有网格，0 个新 Blender 模型，0 个 VFX，0 个 Runtime 判定。预算估计 0.5 人日纹样与映射、0.5–1 人日同屏/四视角调整；不含首次玩家招募。小尺寸识别预期强于 A，但与机关视觉语言混淆的风险更高，因此作为对照而非默认推荐。

## 两方案共同验收安排（未执行）

1. **技术不变项。** 经下一轮授权制作后，由 00/01/09 核对 saved 作者数据、运行时 resolved 坐标、walkable、occludes_light、摄像机与 Gate 条件仍相同；不得只凭材质看起来不透明就宣称逻辑未变。两方案都不增删/移动/缩放 mesh，不改变投射或接收阴影设置，不使用材质位移、透明、裁切或屏幕穿透。保留真实遮挡，即使另一角度挡住角色也不能借此授权隐藏 roof。
2. **统一画面条件。** 由获授权的 00/08 图形工作安排采集；本轮不占窗口。相同存档/姿态/光照、Q0 北/Q1 东/Q2 南/Q3 西、1920×1080 与 1280×720、960×720 原生尺寸比较原版/A/B，共 36 张定态候选截图。截图记录 Build SHA、状态、分辨率与 quadrant；不拿缩小海报代替实机占屏尺寸。至少复核出生位置与角色站在 Gate 的两个姿态是否存在新遮挡；扩展采集数量另列，不能把 36 张说成全部状态。
3. **专家可读性检查。** 看轮廓是否完整不透明、身份纹样在暗侧是否仍可见、道路连接有无被遮掉、标记是否被误认为 Gate、六面锁或可踏檐口。最低像素尺寸只是迭代检查值，不是已验证阈值；必要时减少纹样复杂度，不改相机/体积。
4. **无提示观察。** 找未接触 roof 解释的参与者，每人首次只看一种版本，随机/交替分配，先问“你觉得哪些位置可以停留？为什么？”并记录原话、尝试到达 roof 的行为和犹豫；之后再问该物体可能有什么作用。首问不说 roof、遮光体或不可走。不要让同一个人在已获解释后再试另一版，冒充首次理解改善。
5. **改善判断。** 同条件下，误把 roof 当落脚平台的比例/尝试次数下降，同时把它认作装饰、透明体或可激活机关的比例不增加；角色与合法道路的理解不下降。分别报告样本数、提示曝光、观察到的行为和未知项，不把小样本趋势当通用成功率，不把技术输入 PASS 当认知 PASS。能辨认不可走但未理解遮光用途应分开记，不能合并为“已懂规则”。

本轮是两个最小方案的书面比较。没有新图形验证、没有真人新观察、没有确认新的 P0/P1；roof 的原反馈仍为待分级观察。后续制作、正式美术验收与任何共享 Host 接线均需在本报告之外另行授权，冻结母版不动。
