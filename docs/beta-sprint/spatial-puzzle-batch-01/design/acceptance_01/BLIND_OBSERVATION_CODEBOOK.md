## 帮助曝光等级（逐事件记录，不能事后抹除）

| 等级 | 定义 | 首次独立理解的处理 |
|---|---|---|
| P0 | 主持未提醒；只用游戏实际界面与默认说明 | 可作为独立体验，但游戏内默认说明仍登记 |
| P1 | 中性邀请“你现在在想什么？”或一般设备操作帮助，未指向谜题条件 | 单列elicited与自发；记邀请发生时间，不能冒称自发 |
| P2 | 玩家主动打开游戏提示/H，或主持指向某信息/机制条件 | 保留并转为提示辅助；记录原提示文字，曝光后的独立理解结论受限 |
| P3 | 正确规则、具体路线/按键、答案演示、主持后置表提前暴露 | 该后续部分污染；只可讨论辅助学习/可用性，不作首次迁移证据 |

出现P2/P3不删除此前P0证据。主持若为避免困扰提供帮助，先记录需求与授权，在实际记录中标注帮助；不得为了数据“干净”阻止玩家停止或使用现有提示。

## 事件编码：先原话与实际动作，后解释

| 编码 | 正面可观察事件 | 不能单独算该事件 |
|---|---|---|
| OBS | 自发指出/描述可见信息，或主动比较状态并解释所看内容 | 停顿、Camera动作、鼠标移动、眼睛朝屏幕；无眼动设备不推断注视点 |
| PRED | 动作前具体说出预计变化/不变，记录其后实际结果及是否吻合 | 操作后才解释；仅“试试这个” |
| PLAN | 动作前提出至少一个因果先后或依赖，并按此验证/调整 | 操作很多、路径长；没有原话的连续移动 |
| TEST | 明确提出待检验假设，比较并描述结果；注明是否控制其他变量 | 所有反复操作自动视为系统试验 |
| REVISE | 预测失配后明确修正原因并用下一次行动验证 | 单纯Reset、换键、重复尝试 |
| REUSE | 玩家主动将已学策略用于另一机会，并解释复用关系 | 同题路线背诵、重复通关、主持提示后照做 |
| EXPLAIN | 盲测结束后以自身语言解释结果/反事实 | 主持先给规则，玩家随后复述 |
| TRANSFER | 有明确前题经验、后题未获解法时发生自主策略组合 | 先看答案、同题重玩；不同顺序中未发生学习机会 |
| CONFUSION | 明确错误归因、不确定、寻求帮助或可观察操作困境 | 仅未通关；不将困惑当智力/能力评价 |

同一事件可多码，但不重复计成多名玩家/独立成功。预测错误也可是PRED，记录正确性而不是只收成功预测。无言操作不能反推“没有思考”，应记解释证据不足。

## 全部盲测完成后的开放追问

先问“你觉得刚才为什么能够/没能完成？”“哪些操作改变了结果，哪些你觉得没有关系？”“如果重新开始，你会怎么做？”“这几题之间，你用了哪些相同或不同的方法？”一次一问，保留未知/错误解释，不给答案。记录为P1 elicited；不要将这些话倒填成动作前预测。

所有预定迁移任务结束后才追问。玩家提到具体规则时可问“你是怎样发现的？”或“你觉得换一种做法会怎样？”；不要直接提出正确因素或给特定方向。若后来讲解，再标记P3，之后重试只能作辅助学习。
